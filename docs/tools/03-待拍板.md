# 03 待拍板

> 每项写“推荐 + 备选”。直接勾选或改字即可。本轮已实施（2026-10-29），未提交 git。

## 本轮已完成

- **B1 Overview**
  - `[GUI] OverviewMinScale`（默认 `0.35`）已加入默认模板、示例配置和本机配置。
  - 缩放：`s = max(适配缩放, OverviewMinScale)`，画布可大于屏幕。
  - 视口跟随焦点，`Alt+HJKL` 移到视口外时自动最小幅度平移，带现有动画。
  - 不再设置 120×80 最小窗口尺寸（先按你的要求试无下限）。
  - 退出时用 `OverviewRects` 白名单，保证缩得很小的窗口仍能被 `GetVisibleWindow` 收集并重新平铺。
- **B4 WTM 进入聚焦**
  - `Activate()` 平铺后立即调用 `FocusWindowSafely`，并在 120ms 后补一次；
  - `FocusWindowSafely` 增加 `SetForegroundWindow` + `AttachThreadInput` 兜底；
  - 边框与真实焦点一致。
- **小窗口（cmd）不被捕捉**
  - 全局移除 100px 过滤，只保留 2px 下限；
  - Alt+D、WTM、WinSelect 都能看到小窗口。
- **B2 热键一次触发**
  - `RegHotkey` 默认 `KeyWait(主键)`；普通功能按住只触发一次；
  - WTM 方向/缩放/跨屏、滚轮、拖拽保留连发。
- **B3 托盘菜单拾取窗口**
  - Exclude / Diagnose 改为点击目标窗口后再执行；
  - OSD 提示，Esc 取消，排除自身 GUI 与状态栏。
- **F2 托盘版本号**
  - 托盘菜单顶部加禁用项 `AHK WM vX.Y.Z`。
- **B5 其他桌面窗口被 Alt+D 抓回**
  - `GetVisibleWindow` 跳过最小化窗口；Alt+D 不再跨桌面抓窗口。
- **B6 最小化恢复后不平铺**
  - `_MemberSig` 跳过最小化窗口；恢复时签名变化，自动触发平铺。
- **B7 Overview 分割线重绘 / 移入视口后消失**
  - 分割线改为跟窗口同一套动画平移，不再每次滚动重建。
  - 根因：屏外首次 `Show` 的分层窗口不会被 DWM 合成；改为先在屏内显示再移到真实坐标。
  - 现场验证：5 页 4 条线，左右移动后页缝都有线。
- **B8 切回滚动桌面不归拢屏外窗口 / 归拢改尺寸**
  - `SwitchDesktop` 到滚动桌面时调用 `_GatherDesktop`，把屏外窗口移回该桌面的滚动屏。
  - 归拢跳过最小化窗口；移动用 `SetWindowPos + SWP_NOSIZE`，只改位置不改尺寸。
- **B9 非 WTM 统一光标下窗口**
  - 新增 `_GetTargetHwnd()`；关闭/最小化/最大化/置顶/透明度/吸附/固定/移桌面/排除/诊断/
    终端/编辑器全部改为鼠标下窗口。WTM 内仍用 `FocusHwnd`。

## H. S1 多屏滚动带

- [ ] **H1 布局口径**
  - 推荐：并集口径（窗口可跨显示器边框，算法简单，最像单屏）。
  - 备选：分段口径（不跨屏，复杂）。

- [ ] **H2 高度不一致**
  - 推荐：带高取垂直交集（较矮屏高度）；交集太小则不组成同一条带。

- [ ] **H3 上下两条带**
  - 推荐：页号和滚动互相独立。

- [ ] **H4 配置写法**
  - 推荐：`ScrollableDesktops=1` 表示桌面 1 的所有水平带都滚动；
    `1:2` 表示只让 2 号屏所在的带滚动。
  - 备选：仍只支持 `桌面:显示器`。

- [ ] **H5 跨屏快捷键**
  - 推荐：同一水平带内用带内平移/翻页；`Ctrl+Alt+Shift+H/L` 只用于跨带（上下屏）。
  - 备选：保持物理跨屏语义。

## J. 本轮新发现 / 待确认

- [ ] **J1 Overview 中途重新进入会重置视口**

    视口回到焦点居中，分割线重建；日志里能看到连续多次 `Overview pages=...`。
  - 推荐：保留当前视口与 FocusHwnd，只重算矩形和分割线，不重置 `vx/vy`。
  - 备选：维持现状（成员变化时重排，简单）。

- [ ] **J2 光标在状态栏 / 自身 GUI 上时**
