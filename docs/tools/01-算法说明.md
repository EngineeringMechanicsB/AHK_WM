# 01 算法说明

> 基线：v2.14.0。这里只讲“现在怎么算”和“多屏滚动想怎么算”，不含代码。

## 1. 基本符号

- 显示器 `m` 的平铺区域 `A(m) = (Xm, Ym, Wm, Hm)`（已扣状态栏和边缘间隙）。
- 槽位表 `T(m, n)`：显示器 `m` 上放 `n` 个窗口时，返回 `n` 个归一化矩形
  `s_i = (xlo, xhi, ylo, yhi)`。
- 槽位落屏：`rect_i = (Xm + xlo·Wm, Ym + ylo·Hm, (xhi−xlo)·Wm, (yhi−ylo)·Hm)`，再扣 `WTM_Gap`。
- 自定义规则优先：精确显示器 → `*` 通配 → 内置算法。

## 2. 普通自动平铺

1. 收集当前桌面可平铺窗口，形成顺序 `O`。
2. 按显示器分组，得到每屏窗口列表 `G(m)`。
3. 对每屏取 `T(m, |G(m)|)`。
4. `G(m)` 第 i 个窗口放第 i 个槽位。
5. 记录目标矩形，用于 2px 漂移检测。

布局只依赖“该屏窗口数”，不依赖窗口实际位置。

**例**：1920×1080 屏、3 窗口、规则“1 左半满高、2/3 右侧上下”；
`O=[A,B,C]` → A 左半、B 右上、C 右下；交换 B/C 即交换 `O` 两项。

## 3. 方向聚焦 / 交换

焦点槽位 `i`，方向 `d`：

1. **同带**：过滤出与当前槽位在垂直轴上有区间重叠的候选；没有就取区间距离最小的一批。
2. **完全越过**：候选在移动轴上必须完全越过当前槽位。
3. **最近中心**：取移动轴中心距离最小者，仍并列再比副轴。

聚焦 = 移动焦点；交换 = 交换 `O` 两项；同屏无目标才走像素跨屏兜底。

## 4. 当前滚动模型（v2.14）

- **只有一台滚动屏 `ScrollMon`**，其余屏普通平铺。
- 页数组 `P[1..N]`；每页是“显示器 → 窗口列表”的映射，但只填 `ScrollMon`。
- `ScrollView` 是**一个全局整数页号**。
- 当前页铺满 `ScrollMon`；其它页整体停到所有显示器并集之外。

一页的排法：取该页窗口组 `G`、槽位表 `T(ScrollMon, |G|)`；
当前页原点为 `A(ScrollMon)`，非当前页用“停靠锚点”停到屏幕外。

同步规则：

- 删死窗口、删空页；
- 新窗口进当前页；
- 焦点在别的屏时，新窗口先移到焦点屏；
- 手动全屏时，新窗口进“聚焦窗口页 + 1”。

左右操作：

- 页内：槽位表方向选择；
- 页边聚焦：翻到 `v±1`，取目标页 x 极值窗口；
- 页边移动：窗口插入 `v±1` 的 x 极值槽位，视图跟随；
- 上下：只在本页内，不跨页。

跨屏：`Ctrl+Alt+Shift+H/L` 物理搬运窗口；`Ctrl+Alt+H/L` 聚焦相邻屏当前页的最近窗口。

## 5. 当前 Overview

1. **干跑**布局：不移动窗口，只算出每个窗口“如果现在平铺会在哪”。
2. 滚动页横排：页 p 在 `scroll.x + (p−1)·(页宽 + gap)`，`gap = max(24, 2×WTM_Gap)`。
3. 普通显示器排在页行之后。
4. 所有窗口矩形 + 页矩形取世界外框，得到画布 `cw × ch`。
5. 缩放 `s = max(适配缩放, OverviewMinScale)`，再夹到 1.0；画布可大于屏幕，
   `cw > 视口宽` 或 `ch > 视口高` 时出现视口 `vx/vy`。
6. 视口跟随焦点：`Alt+HJKL` 选到视口外的窗口时，最小幅度平移视口，沿用动画。
7. 窗口按模型矩形缩放，只保留 1px 下限，不再设 120×80。
8. 分割线在页/显示器边界，长度取两侧窗口的实际缩放矩形；记录画布坐标，
   视口平移时与窗口一起动画，不重建。
9. 分层窗口的 `Show` 必须先落在屏幕内，再移到画布坐标；屏外首次显示不会被 DWM 合成。
10. 导航/交换/拖拽只用 `OverviewRects` 模型矩形，不依赖真实窗口矩形。

## 6. 当前模型为什么做不到水平多屏一条带

四个限制：

1. 页的坐标只基于 `ScrollMon`，其它屏没参与页的几何；
2. 页号是全局的，无法上下两条带各自维护页号；
3. 新窗口只路由到 `ScrollMon`；
4. 跨屏是物理搬运，不是同一条带上的平移。

## 7. 目标：水平显示器带

### 7.1 划分带

- 两台显示器若垂直区间有足够重叠、水平方向相接或间隙很小 → 水平相邻；
- 取传递闭包，得到若干**带**；
- 上下堆叠的屏不水平相邻 → 自动成为不同带；
- 带内按左边界排序。

### 7.2 每条带的状态

- 虚拟视口：宽度 = 带内水平并集，高度 = 带内垂直交集；
- 自己的页数组（每页是一个窗口数组）；
- 自己的当前页号；
- 窗口 → 带 / 页 索引。

### 7.3 布局

一页在虚拟视口上取槽位表，窗口按槽位落到整条带上。
窗口可能跨显示器边框（并集口径）。

### 7.4 操作

- 左右：页内方向选择 → 页边翻页（整条带平移）；
- 上下：页内 → 到边则跨到另一条带；
- 新窗口：进焦点所在带的当前页；
- 手动全屏：仍进“聚焦窗口页 + 1”；
- Overview：带内页横排，带与带上下排列。

### 7.5 两种口径

- **并集口径（推荐）**：一页在整条带并集矩形上布局，窗口可跨边框；简单，最接近单屏。
- **分段口径**：每台屏各自布局，共享页号和滚动偏移；不跨边框，但分配规则复杂。

高度不一致时，带高取垂直交集；交集太小则不组成同一条带。

## 8. 例子

**左右两块 1920×1080**：一条带，宽 3840；4 窗口 2×2 网格，1/3 在左屏，2/4 在右屏；
按右翻页整条带左移 3840。

**上下一块 + 左右两块**：上面单独一条带，下面两块一条带；两条带页号独立。

**2×2 四块屏**：上下行之间无垂直重叠 → 两条带，每行一条。

**1080p + 1440p 顶部对齐**：带高取 1080；1440p 下方 360px 不参与该带滚动。
