# 02 当前问题

> 基线：v2.14.0。2026-10-29 已在本地修改并部署（未提交 git）。这里列问题、根因、修复。

## B1 — Alt+O 后窗口“消失”，Alt+D/WTM 忽略（P0 已修）

### 现象

- 窗口很多时进入 Overview，窗口被缩得很小；
- 鼠标能选中，`Alt+←/→` 正常；
- 但 `Alt+D` 忽略一部分窗口，WTM 也当它们不存在，`Alt+HJKL` 选不到。

### 根因

1. Overview 最小尺寸是 `120 × 80`；
2. `GetVisibleWindow()` 会过滤掉宽或高 `< 100px` 的窗口；
3. 被压到 80px 高的窗口退出 Overview 后不再被收集，不进入 `TileOrder`，
   于是平铺和 WTM 都不认它们。

### 已实施（P0 + 修正）

- 去掉 Overview 的 `120×80` 最小尺寸；
- **全局去掉 100px 窗口过滤**：`GetVisibleWindow` 与 `GetVisibleWindowsOnMonitor` 现在只排除
  `< 2px` 的窗口，小 cmd 窗口也能进入 Alt+D / WTM；
- 退出时仍用 `OverviewRects` 白名单兜底：`_OverviewExit` 写入 `Overview_SmallKeep`，
  `GetVisibleWindow` 对白名单内的窗口不再套 2px 下限，`AutoTile` 结束后清空；
- `[GUI] OverviewMinScale` 默认 `0.35`，画布可大于屏幕；
- 视口跟随焦点，`Alt+HJKL` 移到视口外时自动最小幅度平移，带动画；
- 无手动平移键。

### 待观察

- 小窗口进入平铺后是否会出现意外的工具窗口；若发现，优先用排除规则处理，而不是恢复 100px 一刀切。

## B2 — 按住普通热键会反复触发（P1 已修）

### 根因

AHK 热键在按住时随系统自动重复触发。

### 已实施（P1，含修正）

`RegHotkey` 默认加 `KeyWait(主键, "L")` 包装，利用 `#MaxThreadsPerHotkey=1` 忽略重复。

- 关键修正：`NormalizeHotkey` 输出的是 AHK 原生写法（如 `!w`、`^!2`、`!{Enter}`），
  之前直接拿整串当键名，`KeyWait("!w")` 报 `Parameter #1 invalid`，包装失效。
  现在先剥掉 `! ^ + # ~ * $ < >` 再取键名，`{Enter}` 会去掉花括号。
- 应用：桌面切换/移动/跟随、Alt+W、Alt+T、Alt+F、Alt+Q、吸附、平铺、收集、状态栏、重载。
- 排除：WTM 方向/移动/缩放、跨屏移动/聚焦、Alt+滚轮、拖拽、饼菜单。
- 测试先松主键/先松 Alt 两种顺序。

## B3 — 托盘菜单的 Exclude / Diagnose 作用错窗口（P1 已修）

### 现象

从托盘菜单点 `Exclude Current Window` / `Diagnose Window`，焦点跑到菜单，
`WinExist("A")` 拿到的是菜单/任务栏，不是用户想操作的窗口。

### 已实施（P1）

- 两个功能改为接收目标 HWND；
- 菜单路径进入“拾取窗口”模式：
  - OSD 提示 `Pick target window: click it, Esc cancels`；
  - 临时注册 `~LButton` 与 `Esc`；
  - `WindowFromPoint` + `GetAncestor` 取根窗口；
  - 排除脚本自身 GUI 与状态栏；
  - 结果只用 OSD；
  - 拾取完成/取消后注销临时热键。
- 修正：`PickActive` / `PickCb` 已加全局初始化，之前读取未初始化全局直接报错，
  所以菜单点了“没反应”。

## B4 — 进入 WTM 没有真正聚焦（P0 已修）

### 根因

`Activate()` 只设置 `FocusHwnd` 并画边框，没有调用 `FocusWindowSafely()`。

### 已实施（P0 + 修正）

`AutoTile()` 之后、`RefreshBorder()` 之前：

- `FocusHwnd` 无效时回退 `TileOrder[1]`；
- 立即调用 `FocusWindowSafely(FocusHwnd)`；
- **120ms 后再补一次**，避开 Alt/Shift 还没松开导致的激活失败；
- `FocusWindowSafely` 增加 `SetForegroundWindow` + `AttachThreadInput` 兜底；
- 再刷新边框。

## B5 — Alt+D 把其他虚拟桌面的窗口抓回来（已修）

### 根因

`GetVisibleWindow` 不排除最小化窗口，而 v2.14 的 `GetVisibleWindowsOnMonitor` 也没有
`WinGetMinMax = -1` 检查。其他桌面被最小化的窗口因此进入 Alt+D 的候选集。

### 已实施

- `GetVisibleWindow` 直接跳过最小化窗口；
- `GetVisibleWindowsOnMonitor` 再加一层最小化与 2px 保护；
- 其他桌面的窗口不会再被 Alt+D 抓回。

## B6 — Alt+W 最小化后从任务栏恢复，WTM 不自动平铺（已修）

### 根因

`_MemberSig` 使用 `GetVisibleWindow`，而它包含最小化窗口；最小化/恢复不改变成员签名，
慢速检查认为“成员没变”，不会触发 AutoTile。

### 已实施

`_MemberSig` 跳过最小化窗口，因此恢复时成员签名变化，250ms 内触发一次 AutoTile。

## B7 — Overview 分割线在滚动时重绘 / 移入视口后消失（已修）

### 根因

两层问题：

1. 视口平移时调用 `_OverviewDrawDividers` 重建线条，线条瞬间跳到新位置。
2. 线条按画布坐标创建。进 Overview 时焦点在最右页，前几条线的创建坐标是负数。
   分层窗口（GUI + `WinSetTransparent`）第一次 `Show` 落在屏幕外时，DWM 不会合成它；
   之后用 `SetWindowPos` 移进屏幕也不显示。所以只有进 Overview 那一刻已经在屏幕内的线可见，
   往左/右移动后新页缝没有线。

### 已实施

- 分割线记录画布坐标；
- 视口平移时用同一套动画系统移动线条 GUI，不再重建；
- `_OverviewAddLine` 先在屏幕内可见位置 `Show`，再 `_MoveNoResize` 到真实坐标。
  避免“屏外首次显示 → 永不合成”的问题；
- 现场验证：5 页 → 4 条线，进 Overview 后左右移动，三条页缝都能看到。

## B8 — 在别的桌面退出 WTM，切回滚动桌面时屏外窗口不归拢（已修）

### 根因

`Deactivate()` 虽然会调用 `_GatherAllOffscreen()`，但在某些切换顺序下，其他桌面的
`Desktops[d]` 记录与窗口实际状态不同步，切回时仍停在屏外。

### 已实施

`SwitchDesktop` 在 `CurrentDesktop := target` 后，若目标桌面在 `ScrollableDesktops` 中，
调用 `WTM._GatherDesktop(target)`：遍历该桌面记录，把中心在所有显示器之外的窗口移回
目标桌面绑定的滚动显示器（无绑定时回退 1 号屏）。

### 归拢后窗口变小

- 最小化窗口的 `WinGetPos` 返回假的 `160×28` rect；
- 归拢遍历了其他桌面的最小化窗口，`WinMove` 把这个假尺寸写回恢复尺寸；
- 修：归拢跳过所有最小化窗口；移动改用 `_MoveNoResize`（`SetWindowPos + SWP_NOSIZE`），
  只改位置，永不改尺寸。`_GatherAllOffscreen` 与 `_GatherDesktop` 都已处理。

## B9 — 非 WTM 窗口操作目标不统一（已修）

### 现象

`Alt+Q` 关闭的是光标下窗口，但 `Alt+Shift+数字` 移桌面、`Alt+方向` 吸附、
`Ctrl+Alt+T` 固定、`Alt+Shift+X` 排除等用的是**焦点窗口**。

### 已实施

新增 `_GetTargetHwnd()`，非 WTM 统一取鼠标下窗口（排除状态栏）。接入：

- 关闭 `Alt+Q` / `Alt+中键`、最小化 `Alt+W`、最大化 `Alt+F`、置顶 `Alt+T`；
- 透明度 `Alt+滚轮`、吸附 `Alt+方向`、固定 `Ctrl+Alt+T`；
- 移桌面 `Alt+Shift+数字`、携带切换 `Ctrl+Alt+数字`；
- 排除 `Alt+Shift+X`、诊断；
- 终端 `Alt+Enter`、编辑器 `Alt+V`（读取鼠标下资源管理器）。

WTM 模式不变，仍用 `FocusHwnd`。桌面切换里记录焦点仍用活动窗口，仅用于切回恢复。

## S1 — 多显示器水平滚动带

### 现状

- 只有 `ScrollMon` 一台屏参与滚动；
- 页号是全局整数；
- 页的坐标只基于 `ScrollMon`；
- 新窗口只进 `ScrollMon`；
- 跨屏是物理搬运。

### 目标

- 水平多屏像一块整体滚动；
- 上下多屏各自是独立滚动带；
- 每条带有自己的页数组和页号。

### 方案

- 按水平连通划分带；
- 每条带一个虚拟视口（宽=水平并集，高=垂直交集）；
- 一页在虚拟视口上布局；
- 左右翻页整条带平移；上下到边跨带；
- 新窗口进焦点所在带；
- Overview 带内页横排、带间上下排列。

待定：并集口径 vs 分段口径；高度不一致；配置写法；跨屏快捷键；混合 DPI。
